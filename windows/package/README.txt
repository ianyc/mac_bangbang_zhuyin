棒棒注音（Windows 版）使用說明
================================

標準大千鍵盤的注音輸入法，整句選字，會記住你手動選過的字。
適用 Windows 10／11（64 位元），32 位元與 64 位元的程式都能用。


安裝
----
1. 雙擊 BangbangZhuyin-<版本>.msi，照著精靈按「下一步」、「安裝」。
   如果出現「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」（這個安裝檔沒有數位簽章）。
2. 跳出 UAC 時按「是」。安裝位置是 C:\Program Files\BangbangZhuyin。
3. 按 Win + 空白鍵，切換到「棒棒注音」。
   已經開著的程式要重新啟動才會用到。

更新
----
拿到新版的 .msi 後，一樣雙擊安裝，會自動取代舊版，不用先解除安裝。
如果有程式正在使用棒棒注音，會出現「檔案使用中」：選「不關閉應用程式」（預設就是這個）按「確定」，不用關掉那些程式。
也可能出現「安裝程式必須更新在系統執行時所無法更新的檔案或服務…將需要重新開機」：那是因為安裝程式自己的視窗
也載入了棒棒注音，按「確定」繼續就好。
已經開著的程式要重新開啟才會用到新版。最後如果問要不要重新開機，按「否」也可以，舊檔會在下次重新開機時刪掉。

解除安裝
--------
「設定 → 應用程式 → 已安裝的應用程式」找到「棒棒注音」按解除安裝。
也可以再雙擊一次同一個 .msi，選「移除」。
如果問要不要關閉正在使用的程式，選「不關閉應用程式」就好；出現「需要重新開機」的訊息也按「確定」。
選字記憶會保留，以後重新安裝會繼續使用。


基本操作
--------
- 單按 Shift：切換中文／英文（所有程式一起切換）。點工作列上的「中」「英」也可以切換。
- 打注音，空白鍵是一聲；整句會自動選字，按 Enter 送出。
- 選字：游標移到要改的字前面（或在句尾）按 ↓，用數字鍵或 ↑↓＋Enter 選；空白鍵翻頁，Esc 關閉。
- Esc：清掉正在拼的注音；沒有注音時清掉整個組字區。
- 組字中按 Shift 切到英文，組字區會留著，英文接著打在組字區，按 Enter 才一起送出。
- 組字區最多 30 格，超過時最前面的詞自動送出。

標點符號（比照微軟注音）
------------------------
全形標點用 Ctrl，不分中英模式；打出後按 ↓ 可以換成其他符號：
  Ctrl + ,  →  ，（第二個候選是「、」）
  Ctrl + .  →  。
  Ctrl + ;  →  ；
  Ctrl + '  →  、
  Ctrl + [  →  【（候選還有「 『）
  Ctrl + ]  →  】（候選還有」 』）

Shift＋標點是半形：Shift+, → <　Shift+. → >　Shift+1 → !　Shift+9 → (　Shift+0 → )
Shift+; → :　Shift+' → "　Shift+/ → ?　Shift+` → ~
[ ] ' ` 直接按也是半形；Shift + [ ] 是全形的『』。

選字記憶
--------
記在 %APPDATA%\BangbangZhuyin\user-model.json，所有程式共用：一個程式學到的，其他程式下次打字就用得到。
- 刪掉這個檔案就是清除記憶。
- 格式和 Mac 版相同，Mac 的記憶檔可以直接複製過來。
- Microsoft Store 的沙盒程式（例如開始功能表的搜尋）讀不到記憶檔，在那裡學到的選字只在程式開著時有效。

常見問題
--------
- 鍵盤清單裡沒有「棒棒注音」：到「設定 → 時間與語言 → 語言與地區 → 中文（繁體，台灣）→ 語言選項 → 新增鍵盤」加入。
- 某個程式裡還是舊版或打不出字：把那個程式整個關掉再開。瀏覽器關掉視窗後常常還在背景執行，可以登出再登入或重新開機。
- 防毒軟體或 SmartScreen 警告：這個輸入法沒有數位簽章，自己用的話可以放心執行。
